#FontBuilder
FontBuilder is a tools to help player make minecraft font textures-pack
FontBuilder 是一款帮助玩家生成mc字体材质包的工具喵~

如何使用？
根据提示填入对应的选项就好
1,资源包路径：指将字体材质包生成在哪里
2,字体包名称：指材质包名称
3,字体路径：输入要制作成mc字体材质包的路径

如果提示出“出现问题,请将录像反馈至管理员”你可以：
1,重复刚刚的操作将录像发送至pipi_friend@hotmail.com
2,检查资源包路径里是否有与字体包名称相同的文件夹，如果有尝试更改字体包名称
